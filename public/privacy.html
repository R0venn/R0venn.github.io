Vos données restent sur votre appareil

Aucun compte ni service de stockage distant n’est utilisé. Vos fiches et photos sont enregistrées dans le fichier carnet-histoire.json du dossier que vous autorisez. Le navigateur mémorise une référence vers ce dossier pour la prochaine ouverture. Cette autorisation peut être redemandée par le navigateur.

Sur les navigateurs sans accès aux dossiers, les données sont conservées dans le stockage interne du navigateur. Utilisez Télécharger une copie pour obtenir un fichier local. Effacer les données du navigateur efface cette copie interne et le choix du dossier, mais pas les fichiers que vous avez enregistrés dans votre dossier.

Le site est distribué par GitHub Pages, qui reçoit les requêtes normales pour charger l’application. Les fiches et les photos ne sont pas envoyées à GitHub ni à un autre serveur par l’application. Si vous choisissez un dossier synchronisé par OneDrive, iCloud ou un autre logiciel, ce logiciel peut synchroniser les fichiers indépendamment du carnet.

Les fichiers ne sont pas chiffrés par l’application. Protégez votre appareil et conservez des copies indépendantes. Un utilisateur du même profil de navigateur ou ayant accès au dossier peut lire vos données.
